## 2026-10 HTTP2Shell（CVE-2026-111497）— Node.js の Brotli 解凍処理の脆弱性
- 対象期間: 2026-10-21 〜 2026-12-31
- 影響: Node.js を使うアプリ・ツール。Mac の場合は Node.js 本体と、Node.js を中に持つアプリ（Electron 製アプリ）
- 確認すること:
  - 棚卸しの「Node.js」が **v22.23.4 以上（22系）／v24.22.1 以上（24系）／v26.12.1 以上（26系）** か。20系以下なら更新が必要
  - 棚卸しの「（Electron）」付きアプリ（Slack・VS Code・Cursor・Notion・Obsidian など）は、各アプリの「アップデートを確認」で最新にする。2026-10-23 時点では Electron の安定版に修正が入っておらず、最新にしても未修正の可能性がある。その場合は「アプリ側の修正待ち」とレポートに残す
- 直し方: Homebrew で入れている場合は `brew upgrade node`。nodenv・nvm などで入れている場合は、そのツールで修正版を入れる
