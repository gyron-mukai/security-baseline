# 直し方（checks.tsv の ID ごと）

- 画面の名前は macOS 26〜27 の「システム設定」を基準にしている。OS のバージョンによって表記や場所が少し違うことがある。見つからないときは、システム設定の左上の検索欄に【検索語】を入れると早い
- `sudo` が付くコマンドは Claude Code からは実行できない（パスワード入力が必要なため）。本人に「ターミナル」アプリを開いてもらい、1行ずつ貼り付けてもらう
- 直したあとは、もう一度点検して ✅ になったことを確かめる

## アプリの更新（棚卸し・脆弱性情報で更新を勧めるとき）
アプリごとに場所が違う。上から順に探してもらう。
1. 画面上部のメニューバーで、**アプリ名のメニュー**（例: 「Slack」）→「アップデートを確認」「Check for Updates」
2. 見つからなければ「**ヘルプ**」メニュー →「アップデートを確認」
3. App Store で入れたアプリ → App Store アプリ →「アップデート」
4. Microsoft Office → どれか1つ（Word など）を開き、「ヘルプ」→「更新プログラムのチェック」（Microsoft AutoUpdate が開く）
5. Adobe 製品 → Creative Cloud アプリの「アップデート」
6. Homebrew で入れたアプリ（棚卸しで Homebrew ありの人）→ ターミナルで `brew upgrade --cask アプリ名`
7. それでも無い場合は、アプリを終了して開き直すと自動で更新されるものもある（Slack・VS Code・Notion など）。ダメなら公式サイトから最新版を入れ直す

## os-update
- システム設定 → 一般 → ソフトウェアアップデート → 「今すぐアップデート」【検索語: ソフトウェアアップデート】
- 再起動が必要。作業中のファイルを保存してから行う
- **大型アップグレード**（例: 26 → 27 のように最初の数字が変わるもの）は、会社で使うアプリや VPN が対応しているか確認してから。表示がそれだけなら、急がなくてよいと伝える。同じ数字の中の更新（26.6 → 26.7 など）はすぐ適用する

## auto-security-update
- システム設定 → 一般 → ソフトウェアアップデート → 「自動アップデート」の ⓘ → 「セキュリティ対応とシステムファイルをインストール」を ON【検索語: 自動アップデート】

## filevault
- システム設定 → プライバシーとセキュリティ → FileVault → 「オンにする」【検索語: FileVault】
- 途中で出る**復旧キーは必ず控える**（iCloud アカウントで解除する方式を選んでもよい）。復旧キーを PC 内の平文ファイルに保存しない
- 暗号化は裏で進み、その間も PC は使える

## sip
- SIP が無効になっているのは普通ではない（誰かが意図的に切った可能性がある）。本人だけで直そうとせず、**向井さんに連絡**してもらう
- 戻し方（参考）: 復旧モードで起動 → ユーティリティ → ターミナル → `csrutil enable` → 再起動

## gatekeeper
- 次の1行をターミナルで実行し、パスワードを入れる: `sudo spctl --master-enable`
- そのあと、システム設定 → プライバシーとセキュリティ → 「アプリケーションの実行許可」が「App Store と既知のデベロッパ」になっているか確認する

## firewall
- システム設定 → ネットワーク → ファイアウォール → ON【検索語: ファイアウォール】

## auto-login-off
- システム設定 → ユーザとグループ → 「自動ログイン」を「オフ」【検索語: 自動ログイン】

## screen-lock
- システム設定 → ロック画面 → 「スクリーンセーバの開始後またはディスプレイがオフになったあとにパスワードを要求」を「すぐに」または「5分以内」にする【検索語: ロック画面】

## remote-ports
- 結果に出たポート番号で判断する
  - 22番: システム設定 → 一般 → 共有 → 「リモートログイン」を OFF
  - 445 / 548番: 同じ画面の「ファイル共有」を OFF
  - 5900番: 同じ画面の「画面共有」「リモートマネージメント」を OFF
  - 3283番: 「リモートマネージメント」を OFF
  - 3389番: Windows 用のリモートデスクトップ系アプリ。何のアプリか本人に確認する
- 業務で必要な場合（社内サポートで画面共有を使う等）は、無理に止めず、その旨をレポートに残す

## stealth
- システム設定 → ネットワーク → ファイアウォール → オプション → 「ステルスモードを有効にする」を ON
- 画面で見つからない場合はターミナルで: `sudo /usr/libexec/ApplicationFirewall/socketfilterfw --setstealthmode on`

## airplay-receiver
- システム設定 → 一般 → AirDrop と Handoff → 「AirPlay レシーバー」を OFF【検索語: AirPlay】
- iPhone ミラーリングはこれを切っても使える

## guest-off
- システム設定 → ユーザとグループ → 「ゲストユーザー」の ⓘ → 「ゲストユーザーにこのコンピュータへのログインを許可」を OFF

## appstore-auto-update
- App Store アプリを開く → メニューバーの App Store → 設定 → 「自動アップデート」を ON

## timemachine
- 外付けのディスク（容量は Mac の2倍以上が目安）を用意し、システム設定 → 一般 → Time Machine → 「バックアップディスクを追加」【検索語: Time Machine】
- 登録時に **「バックアップを暗号化」を必ず ON** にする。暗号化の選択肢が出ない場合は、そのディスクに古いバックアップが残っている可能性がある（消去してから登録し直す）
- ディスクが無い場合は、無理に今やらず「推奨の残り」としてレポートに残す

## claude-deny
- `~/.claude/settings.json` の `permissions.deny` に、少なくとも次の3種類を入れる。**既存の設定を消さずに追記**すること。追記する前に、変更内容を本人に見せて了承を取る
  - 機密ファイルの読み取り禁止: `Read(//**/.env*)`, `Read(//**/credentials*)`, `Read(//**/secrets*)`, `Read(//**/*.pem)`, `Read(//**/*.key)`
  - SSH 鍵の読み取り禁止: `Read(//**/id_rsa*)`, `Read(//**/id_ed25519*)`, `Read(//**/id_ecdsa*)`
  - 管理者権限の禁止: `Bash(sudo *)`
- ファイルが無い場合は、次の内容で新規作成してよい（本人の了承後）
  ```json
  {
    "permissions": {
      "deny": [
        "Read(//**/.env*)", "Read(//**/credentials*)", "Read(//**/secrets*)",
        "Read(//**/*.pem)", "Read(//**/*.key)",
        "Read(//**/id_rsa*)", "Read(//**/id_ed25519*)", "Read(//**/id_ecdsa*)",
        "Bash(sudo *)"
      ]
    }
  }
  ```
- 反映は Claude Code の再起動後

## claude-no-bypass
- `~/.claude/settings.json` の `permissions.defaultMode` が `bypassPermissions` なら、その行を消すか `default` にする。`skipDangerousModePermissionPrompt` が `true` なら消す。どちらも本人の了承を取ってから編集する
- 起動時に `--dangerously-skip-permissions` を付ける習慣がないかも本人に聞く（付けていたらやめてもらう）
